# 接口、数据流与通信语义

## 接口和类型

接口证据需要关联 VI、Connector Pane 槽位、控制器／指示器、图内节点端子、IR port_id 和类型。VI 输入常对应图内 output 方向，VI 输出对应图内 input 方向，不能直接按图端口方向命名函数参数。

局部端子索引可能重复为 0，不能用于连接器排序。物理槽位可以不连续；输入、输出分别排序后映射连续 MATLAB 参数位置，同时保留原槽位。单输入／单输出也需要证明接口清单完整，不能只因只解析到一个端口就认为完整。

类型至少要满足当前候选的完整语义：数值表示与位宽、符号、数组维度、布尔、字符串、Cluster 字段与顺序、枚举及资源引用。未知扩展字段保留不代表已理解。必要的转换必须有明确规则，不把未知值默认为 double。

## 数据流和结构

- 仅处理已实现语义的数据边。TUNNEL、LOOP_CARRY、FEEDBACK、CHANNEL、CONDITIONAL_DATA 不能统一当普通表达式边。
- 验证端口方向、输入唯一生产者、输出定义、类型兼容、缺失输入和常量值完整性。
- fan-out 复用同一值；同一节点和 SubVI 的多个输出来自一次求值。
- 保留 Case、Loop、Sequence、隧道和移位寄存器的层级、条件和作用域。循环状态、分支出口、执行约束没有证据时不能展平猜测。
- 写入、等待、设备状态等效果不仅看拓扑，还要验证实际错误线、序列结构或其他明确约束建立的顺序。

## SubVI

分别证明：调用确实存在于 Block Diagram；Call Site 对应正确节点；callee 路径解析唯一；双方端口和类型匹配；实参与形参绑定；重复调用与多输出的执行次数正确。

路径别名按可核查的工程规则解析，不能因 basename 一样便认作同一个 VI。只补候选依赖闭包；无关的解析失败不自动进入范围。递归或调用环需要显式支持策略，否则阻塞。

## 资格与 diagnostics

IR 的 KNOWN/PARTIAL/UNKNOWN/UNSUPPORTED/UNAVAILABLE 描述知识状态，与生成器支持状态分开。VI 总状态 PARTIAL 可能仅由非执行警告引起，需要查看具体实体；KNOWN 也不自动代表支持生成。

分类处理注释、低层解析警告、执行节点、类型和调用证据。确认不参与执行的注释可以保留并忽略其执行影响；连接关系不明的实体不能随意当注释。候选所需信息 UNAVAILABLE 时阻塞；不相关的信息缺失只记录影响范围。

## VISA、等待和错误

源 LabVIEW 的行为契约与目标 MATLAB API 契约分别核实，并记录独立来源及适用版本。不要拿不相干函数的错误／warning 规则套到 VISA Write。

本项目单写入案例采用的转换约定：

| 情形 | 已约定结果 |
|---|---|
| 输入 error.status=true | 不写入，原样返回 error 和资源 |
| 输入无错误 | 一次写入，成功后返回原错误 Cluster 与同一资源 |
| 输入 warning（status=false，code 非零） | 允许写入；成功保留 warning |
| 写入异常／模拟超时 | 转换器错误 status=true，code=int32(-2147483648)，source 含异常标识与消息；保留资源 |

这是已核验案例的契约，不是所有 NI 函数的通用定律；保留 converter 错误与原生 NI 错误的区别。

该案例源 execution_mode=UNKNOWN，目标使用等待写入完成或超时后返回的策略。未知模式仅在已经批准的单写入函数行为范围内不构成阻塞；不得将这项例外扩展成所有未知语义均可生成，也不声明线程占用、并发或实时等价。

精确记录 write 参数中的命令内容和是否追加 CR/LF。Fake 捕获的字节／字符串不证明真实 VISA 的 EOI、设备终止配置或物理传输行为。

## 命令格式

字符串模板、格式符、精度、数值表示、单位、标点、分隔符和终止符来自 VI 常量与实际格式化节点。只实现有证据的格式子集；遇到未支持格式明确失败，不以通用格式化近似替代。

驱动型号和手册型号分别列出。DG1022/DG1022U 与 DG1022Z／DG1000Z 不因名称相近而兼容。对另一个系列（例如 DSA800）使用其适用材料，不能把信号源命令迁移到频谱分析仪。
